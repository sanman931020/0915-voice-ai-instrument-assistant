# 語音 AI 樂器推薦助手

這是一個完全獨立的語音 AI 網頁應用程式。GitHub Pages 提供可取得麥克風權限的頂層前端，GAS 安全保存 API 金鑰並呼叫 Gemini，從固定清單中推薦 1–3 種樂器。

## 專案檔案

- `Index.html`：完整介面、樣式、語音辨識與前端互動。
- `Code.gs`：GAS 網頁入口、GitHub Pages 橋接、Gemini 呼叫、輸入與回傳驗證。
- `appsscript.json`：GAS V8 執行環境與外部請求權限。

本專案不需要 npm、外部 JavaScript 套件、圖片、音訊、試算表或其他案例檔案。

## 建立 GAS 專案

1. 開啟 [Google Apps Script](https://script.google.com/)，建立新專案。
2. 將 `Code.gs` 全部內容貼入 GAS 的程式碼檔。
3. 新增 HTML 檔，名稱輸入 `Index`，再貼入 `Index.html` 全部內容。
4. 在「專案設定」開啟資訊清單檔案，將 `appsscript.json` 內容貼入。
5. 儲存專案。

請勿把 Markdown 程式碼圍欄、README 或真實 API 金鑰貼入 `Index.html`。

## 設定 Gemini

進入「專案設定 → 指令碼屬性」，新增：

| 屬性 | 內容 |
|---|---|
| `GEMINI_API_KEY` | 自己從 Google AI Studio 取得的 API 金鑰 |
| `GEMINI_MODEL` | 帳號目前可用、支援 `generateContent` 與 JSON schema 的模型名稱 |

模型名稱只填名稱本身，不包含網址或 `models/`。API 金鑰只放在 Script Properties，不可寫入前端或公開文件。

設定後，在 GAS 編輯器的函式選單執行 `checkSetup_`。成功時只會在執行記錄顯示設定存在，不會呼叫 Gemini，也不會消耗生成額度。

## 部署成網頁應用程式

1. 選擇「部署 → 新增部署」。
2. 類型選擇「網頁應用程式」。
3. 設定為「以我執行」；若 GitHub Pages 要呼叫後端，存取權必須選「所有人」。
4. 完成授權，開啟部署後以 `/exec` 結尾的網址。
5. GAS 頁首應顯示「GAS 後端模式｜語音請使用公開版」。

修改程式後必須建立新版本並更新部署，否則 `/exec` 可能仍顯示舊內容。

## 使用方式

一般模式請開啟 GitHub Pages 公開語音版；GAS 會將 HTML 放在沙盒 iframe，Chrome 可能拒絕該框架使用語音辨識。

公開語音版：

1. 按「開始說話」並允許麥克風權限。
2. 說出需求，例如「我住公寓，想練節奏但不能太吵」。
3. 核對辨識文字，再按「請 AI 推薦樂器」。

開發者模式：

1. 勾選「開發者模式」。
2. 可明確切換「麥克風」或「文字輸入」。
3. 下方會顯示原始文字、請求內容、執行狀態和 AI JSON。

GitHub Pages 透過受驗證的 JSONP 橋接呼叫 GAS；GAS 頁面內仍使用 `google.script.run`。直接開啟本機 `Index.html` 時不會呼叫 Gemini；「載入固定示範」只顯示程式內建資料。

Gemini Preview 偶爾需要 20–60 秒。畫面會持續顯示已等待秒數，送出期間按鈕會停用，避免重複呼叫。

## 建議測試

### 模糊語意

- 「我想學一種簡單、可以帶去學校的樂器。」
- 「住公寓，想練節奏但不能太吵。」
- 「喜歡爵士樂，希望聲音有力量。」
- 「想學一個好玩的。」

最後一句資訊不足，結果應列出未確認條件，不應自行假設預算、住處或經驗。

### 語音與模式

- 允許及拒絕麥克風權限。
- 開始後手動停止、沒有說話、重新錄音。
- 在開發者模式切換文字輸入時，確認麥克風會停止。
- 使用不支援語音的瀏覽器時，確認系統自動開啟文字輸入。

語音辨識通常需要 Chrome／Edge，以及 HTTPS 或 localhost。瀏覽器、作業系統、網路和學校政策都可能影響語音功能。

### 後端錯誤

- 暫時移除 `GEMINI_API_KEY`，應顯示缺少設定。
- 填入不存在的模型，應顯示模型錯誤。
- 額度耗盡或呼叫過快時，應顯示稍後再試。
- 空白文字不能送出，文字長度不得超過 2000 字。
- AI 若回傳清單外樂器、重複樂器、超過三筆或欄位錯誤，後端必須拒絕結果。

## 安全與限制

- 使用者文字被視為待分析資料，不能覆寫系統規則。
- 前端只用 `textContent`／文字節點呈現使用者及 AI 內容。
- 不保存對話、不建立帳號、不連商店，也不提供即時價格。
- 本專案沒有公開服務的流量限制。課堂測試請使用非敏感文字，並先限制網站存取權。
- AI 推薦僅供探索；購買前仍應實際試奏並請教合格教師或樂器行。
